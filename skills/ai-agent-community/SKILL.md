# AI Agent Community

系统用户级 Agent 注册登记表位于系统用户级 Agent 根目录中的 `AGENTS.md`，仅登记本机当前系统用户环境下可跨项目调用的 Agent 根目录与职责。

## 查看注册登记表

读取系统用户级 Agent 根目录中 `AGENTS.md` 的"注册 Agent"小节，按职责选择 Agent、按根目录定位；调用时按其中的"使用约定"加载目标 Agent 的定义与适用 skill。

## 写入范围

- 仅新增或更新目标 Agent 条目；其他注册条目和"使用约定"保持原样，除非用户明确要求修改。

## 注册前检查

1. 确认待注册 Agent 的根目录及其 `AGENTS.md` 存在；缺失 `AGENTS.md` 时先补齐，完成前不注册。
2. 按登记表的"使用约定"读取目标 Agent 的 `AGENTS.md`，核实职责描述与实际定位一致。具体能力、使用权限与操作约定以目标 Agent 的 `AGENTS.md` 及适用 skill 为准。
3. 按根目录检查现有登记表：已注册时更新原条目，未注册时在"注册 Agent"小节末尾新增，避免重复登记。

## 条目格式

在"注册 Agent"小节末尾沿用以下格式新增或更新条目：

```markdown
### <Agent 中文名>（<Agent 英文名>）

- **Agent 根目录**：`<绝对路径，正斜杠>`
- **职责**：<一两句话说明该 Agent 管什么、收录什么>
```

编写要求：

- Agent 根目录使用绝对路径和正斜杠。
- 每个条目以 Agent 中文名和英文名作为标题，正文仅保留 Agent 根目录与职责两项，以根目录识别是否重复登记。
- 名称与 Agent 实际定位一致；职责简述管理范围与主要工作，不另设对外能力、skill 清单或调用条件等注册内容。

## 验证

完成后检查：

- 目标 Agent 根目录及 `AGENTS.md` 真实存在，职责描述有依据。
- 条目保留名称标题，正文仅包含 Agent 根目录与职责两项，格式符合模板。
- 目标 Agent 只登记一次，登记表其他内容保持原样。
